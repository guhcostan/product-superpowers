# Product Superpowers — Contributor Guidelines

## If You Are an AI Agent

Stop. Read this section before doing anything.

This repo contains skills that shape PM agent behavior. Quality matters. If you are contributing:

1. Read existing skills to understand conventions (frontmatter, hard gates, checklists, red flags, process flows)
2. Test your changes across multiple sessions before submitting
3. Do not modify carefully-tuned content (Red Flags tables, "human partner" language) without evidence the change improves outcomes
4. One skill change per PR

## What We Will Not Accept

- Rewrites that change the project's voice without understanding why it exists
- Bulk PRs — pick ONE thing and do it well
- Skills without proper hard gates and red flags
- Fabricated content or hallucinated frameworks
- Domain-specific additions that don't benefit all PMs

## General

- MIT license
- Skills must work across both Claude Code and OpenCode
- Follow the SKILL.md format: frontmatter, overview, when to use, process, checklists, hard gates, red flags
