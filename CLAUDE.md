# Product Superpowers — Agent Instructions & Contributor Guidelines

## If You Are an AI Agent Using This Repo

You have Product Superpowers installed. This is a set of composable skills for product management — from discovery through launch.

**The first thing you MUST do in every session** is load the skill `product-superpowers/using-product-superpowers` and follow it. The bootstrap skill teaches you how to find, invoke, and use all 17 skills.

## Philosophy

- **Discovery before requirements** — Understand the problem before writing what to build
- **Outcomes over outputs** — Measure success by business impact, not features shipped
- **Evidence over opinions** — Validate with data and user research, not intuition
- **Systematic over ad-hoc** — Process over guessing

## If You Are Contributing to This Repo

Stop. Read this section before doing anything.

This repo contains skills that shape PM agent behavior. Quality matters. If you are contributing:

1. Read existing skills to understand conventions (frontmatter, hard gates, checklists, red flags, process flows)
2. Test your changes across multiple sessions before submitting
3. Do not modify carefully-tuned content (Red Flags tables, "human partner" language) without evidence the change improves outcomes
4. One skill change per PR

## What We Will Not Accept

- Rewrites that change the project's voice without understanding why it exists
- Bulk PRs — pick ONE thing and do it well
- Skills without proper hard gates and red flags
- Fabricated content or hallucinated frameworks
- Domain-specific additions that don't benefit all PMs
